# Ledger-merger（図面親子管理台帳 統合ツール）

DXF-diff-manager の複数の出力フォルダにある台帳ファイル（`図面親子管理台帳.xlsx` の
`Diff List` シート）を1つの Excel ファイルに統合する Streamlit アプリです。

## 機能

- 複数の DXF-diff-manager 出力フォルダを一括して処理
- 台帳ファイルはファイル名ではなくシート内容（`Diff List` + `Summary` シートの存在）で判定
  （`diff_labels.xlsx` / `unchanged_labels.xlsx` は台帳ではないため候補から除外）
- `Diff List` のうち `Total Entities` が空欄の行（実際には差分抽出されていない図番ペアの
  関係記録）は統合対象から除外する（`Summary` シートの「差分抽出ペア数」と同数の行のみ統合される）
- 統合 Excel には `Child` 列の左に `Diff Package`（出力フォルダ名）列を追加
  - 各出力フォルダのブロックの先頭行のみ黒字、それ以外は薄いグレー文字で表示し、ブロックの境目を視認しやすくする
- 各ブロックの先頭行には `Total Entities` 列の後ろに、`Summary` シートの以下9項目を記載
  - 削除図形数 合計 / 追加図形数 合計 / 差分図形数 合計 / 変更なし図形数 合計 / 総図形数 合計 /
    図形変更率 [%] / 入力図面総数 / 差分抽出ペア数 / 流用率 [%]
- 台帳ファイルが見つからない出力フォルダはスキップし、フォルダ名のみを一覧表示する（処理全体は継続）

## インストール（ローカル開発環境）

```bash
cd Ledger-merger/
pip install -r requirements.txt
streamlit run app.py
```

## 使用方法

### 入力方法

DXF-diff-manager の出力フォルダ群を ZIP 化してアップロードします（複数可）。
Streamlit Cloud にはサーバー側ローカルファイルシステムがなく、ブラウザの
`file_uploader` はフォルダ構造を保持できないため、ZIP アップロードのみに統一しています。

### 基本的なワークフロー

1. 対象フォルダを ZIP 化してアップロードする
2. 「統合実行」ボタンを押す
3. 統合された Diff Package 数と、台帳ファイルが見つからなかったフォルダ名の一覧を確認する
4. 「統合Excelをダウンロード」ボタンで結果を取得する

### 出力ファイル形式

- ファイル名: `統合_図面親子管理台帳_<YYYYMMDD_HHMMSS>.xlsx`
- シート名: `Diff List`（1シートのみ）
- 列構成（22列）:

  | 列 | 内容 |
  |---|---|
  | A | Diff Package（出力フォルダ名） |
  | B〜M | 元の Diff List シートの全列（Child 〜 Total Entities） |
  | N〜V | Summary シートの9項目（各ブロックの先頭行のみ） |

## よくある問題

- **「有効な台帳ファイルが見つかりませんでした」と表示される**
  → アップロードした ZIP の中に `Diff List` と `Summary` の両シートを持つ
    `.xlsx` が存在するか確認してください。ファイル名は問いません。
