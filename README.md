# Ledger-merger（図面親子管理台帳 統合ツール）

DXF-diff-manager の複数の出力フォルダにある台帳ファイル（`Diff List` シート）を
1つの ZIP（`統合図面台帳.zip`）に統合する Streamlit アプリです。

## 機能

- 複数の DXF-diff-manager 出力フォルダを一括して処理
- 台帳ファイルはファイル名ではなくシート内容（`Diff List` + `Summary` シートの存在）で判定
  （`diff_labels.xlsx` / `unchanged_labels.xlsx` は台帳ではないため候補から除外）
- 元DXFファイルを格納する `dxf図面` 等の非xlsxサブフォルダが出力フォルダに付随していても、
  台帳を正しく検出する
- `Diff List` のうち `Total Entities` が空欄の行（実際には差分抽出されていない図番ペアの
  関係記録）は統合対象から除外する
- 台帳ファイルが見つからない出力フォルダはスキップし、フォルダ名のみを一覧表示する（処理全体は継続）
- 統合実行のたびに `統合図面台帳.zip` を1つ生成し、以下の3種類を含める:
  - **`図形変更量詳細.xlsx`** — 全 Diff Package を1シートに集約した統合Excel
    （`Diff Package` 列でブロック化。各ブロックの先頭行のみ黒字、それ以外は薄いグレー文字）
  - **`統合図面管理台帳.xlsx`** — `Child`-`Parent` ペア単位でユニーク化した `Master` シート
    のみのExcel。前回ダウンロードした同ファイルをアップロードすると、同じペアは今回のデータ
    で上書きしつつ、それ以外のペアは保持したまま蓄積する
  - **`指番_モジュール_サイド別集計/`** — DXF-diff-manager のZIPダウンロードファイル名
    （`指番_モジュール_サイド_リビジョン`）単位で、レビジョン横断のSummary・Diff Listを
    まとめたExcelを1グループ1ファイルで格納するフォルダ

## インストール（ローカル開発環境）

```bash
cd Ledger-merger/
pip install -r requirements.txt
streamlit run app.py
```

## 使用方法

### 入力方法

1. **ZIPファイル（複数可）** — DXF-diff-manager の出力フォルダ群を ZIP 化してアップロード
   します。Streamlit Cloud にはサーバー側ローカルファイルシステムがなく、ブラウザの
   `file_uploader` はフォルダ構造を保持できないため、ZIP アップロードのみに統一しています。
2. **統合図面管理台帳.xlsx（必須）** — 前回この画面からダウンロードした
   `統合図面管理台帳.xlsx` をアップロードします。今回の結果と蓄積・上書きした最新版を
   出力するために必要です。

### 基本的なワークフロー

1. 対象フォルダを ZIP 化してアップロードする
2. 前回ダウンロードした「統合図面管理台帳.xlsx」をアップロードする
3. 「統合実行」ボタンを押す
4. 統合された Diff Package 数と、台帳ファイルが見つからなかったフォルダ名の一覧を確認する
5. 「統合台帳をダウンロード」ボタンで `統合図面台帳.zip` を取得する

### 出力ファイル形式

`統合図面台帳.zip` の中身:

```
統合図面台帳.zip
├── 図形変更量詳細.xlsx
├── 統合図面管理台帳.xlsx
└── 指番_モジュール_サイド別集計/
    ├── {指番}_{モジュール}_{サイド}_all.xlsx
    └── ...（グループごとに1ファイル）
```

**`図形変更量詳細.xlsx`**（シート名: `Diff List`、22列）

| 列 | 内容 |
|---|---|
| A | Diff Package（出力フォルダ名） |
| B〜M | 元の Diff List シートの全列（Child 〜 Total Entities） |
| N〜V | Summary シートの9項目（各ブロックの先頭行のみ） |

**`統合図面管理台帳.xlsx`**（シート名: `Master` のみ、12列）

`図形変更量詳細.xlsx` の Diff List から `Child`-`Parent` ペアでユニーク化し、`Child` の
昇順で並べたもの（B〜M列と同じ12列構成）。

**`指番_モジュール_サイド別集計/{指番}_{モジュール}_{サイド}_all.xlsx`**

`Summary` シート（`TOTAL` 列 + レビジョン列ごとの値）と `Diff List` シート（`Child` ごとに
集計、`Diff Package`・合計列は含まない12列）の2シート構成。DXF-diff-manager の
ZIPダウンロードファイル名の命名規則（`dxf_diff_results_Type{A/B/C}_{指番}_{モジュール}_
{サイド}_{リビジョン}`）に一致するフォルダのみが対象。

## よくある問題

- **「有効な台帳ファイルが見つかりませんでした」と表示される**
  → アップロードした ZIP の中に `Diff List` と `Summary` の両シートを持つ
    `.xlsx` が存在するか確認してください。ファイル名は問いません。
- **「統合実行」ボタンが押せない**
  → ZIPファイルと「統合図面管理台帳.xlsx」の両方をアップロードしてください
    （どちらも必須です）。初めて使う場合も、`Master` シートだけの空のExcelファイル
    （1行目のヘッダーのみ）を用意してアップロードしてください。
- **アップロードした「統合図面管理台帳.xlsx」が反映されない**
  → シート名が `Master`、ヘッダー行が想定の12列と一致しているか確認してください。
    一致しない場合は警告を表示した上で、今回分のデータのみで新規作成します。
